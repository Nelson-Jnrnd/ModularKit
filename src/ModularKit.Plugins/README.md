# ModularKit.Plugins

Startup plugin discovery, service registration and polymorphic JSON.

Targets .NET 10. Initial preview; packages are built locally or obtained from repository CI artifacts.

See the [usage guide](https://github.com/Nelson-Jnrnd/ModularKit/blob/main/docs/plugins.md) and [complete sample](https://github.com/Nelson-Jnrnd/ModularKit/tree/main/samples/DeviceWorkbench).

Build this package from the repository root:

```sh
dotnet pack src/ModularKit.Plugins/ModularKit.Plugins.csproj -c Release -o artifacts/packages
```
