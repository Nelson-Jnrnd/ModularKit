# ModularKit.Configuration

Named configuration trees, references, metadata and topic-based JSON.

Targets .NET 10. Initial preview; packages are built locally or obtained from repository CI artifacts.

See the [usage guide](https://github.com/Nelson-Jnrnd/ModularKit/blob/main/docs/configuration.md) and [complete sample](https://github.com/Nelson-Jnrnd/ModularKit/tree/main/samples/DeviceWorkbench).

Build this package from the repository root:

```sh
dotnet pack src/ModularKit.Configuration/ModularKit.Configuration.csproj -c Release -o artifacts/packages
```
