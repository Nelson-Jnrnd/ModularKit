# ModularKit.Configuration.Blazor

Configuration tree and generated forms using Blazor Server and MudBlazor 9.11.

Targets .NET 10. Initial preview; packages are built locally or obtained from repository CI artifacts.

See the [usage guide](https://github.com/Nelson-Jnrnd/ModularKit/blob/main/docs/editor.md) and [complete sample](https://github.com/Nelson-Jnrnd/ModularKit/tree/main/samples/DeviceWorkbench).

Build this package from the repository root:

```sh
dotnet pack src/ModularKit.Configuration.Blazor/ModularKit.Configuration.Blazor.csproj -c Release -o artifacts/packages
```
