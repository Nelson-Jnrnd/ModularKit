# ModularKit.Persistence.Json

JSON file storage with temporary writes, replacement and backups.

Targets .NET 10. Initial preview; packages are built locally or obtained from repository CI artifacts.

See the [usage guide](https://github.com/Nelson-Jnrnd/ModularKit/blob/main/docs/persistence.md) and [complete sample](https://github.com/Nelson-Jnrnd/ModularKit/tree/main/samples/DeviceWorkbench).

Build this package from the repository root:

```sh
dotnet pack src/ModularKit.Persistence.Json/ModularKit.Persistence.Json.csproj -c Release -o artifacts/packages
```
